# Galeria de temas

Temas prontos para o Compasso Player e para o Caixinhas Orologia (o formato é o mesmo).

Para usar um tema deste diretório: abra o arquivo `.json`, copie o conteúdo e, no app, vá em **Ajustes › Compartilhar tema › Colar JSON**. Os temas da galeria também aparecem dentro do Compasso, em **Ajustes › Galeria**, sem precisar de internet.

Quer mandar o seu? Crie o tema no app, toque em **Baixar .json** e abra um pull request colocando o arquivo aqui.
