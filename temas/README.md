# Galeria de temas

Temas prontos para o Orolon Player e para o Caixinhas Orologia (o formato é o mesmo).

Para usar um tema deste diretório: abra o arquivo `.json`, copie o conteúdo e, no app, vá em **Ajustes › Compartilhar tema › Colar JSON**. Os 14 temas desta pasta já vêm prontos no Orolon Player e no Orolon Caixinhas, em **Ajustes › Aparência**, sem precisar de internet. O campo `brilho` (opcional) é a cor do clarão parado no alto da tela; sem ele, o clarão segue o destaque.

Quer mandar o seu? Crie o tema no app, toque em **Baixar .json** e abra um pull request colocando o arquivo aqui.
